# 메뉴 이미지 배치

디굴디굴은 `config.js`의 합체 단계와 아래 파일명을 기준으로 `assets/menu/`에서 이미지를 읽습니다.

Google Drive 공개 폴더에서 확인된 11종 파일:
- 로투스 수플레.png
- 꿀자몽빙수.png
- 밤 수플레.png
- 흑임자 수플레.png
- 복숭아 수플레.png
- 옛날인절미팥빙수.png
- 두바이초코 수플레.png
- 코코망고리치빙수.png
- 인절미 수플레.png
- 흑임자빙수.png
- 크림브륄레 수플레.png

원본 PNG는 투명 배경 1254×1254 기준입니다.

## 적용 규칙

1. 파일명은 위 이름과 정확히 맞춥니다.
2. 이미지 자체의 투명 여백과 물리 충돌 반경은 별개입니다. 충돌 반경은 `config.js`의 `diameter` 계수로 계산합니다.
3. 이미지 파일이 아직 없거나 로딩에 실패하면 게임은 자동으로 색상 원형 fallback을 사용합니다.
4. 실제 메뉴 이미지를 배치한 뒤 스마트폰에서 작은 메뉴 1~5단계의 식별성을 먼저 확인합니다.
