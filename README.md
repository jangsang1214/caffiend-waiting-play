# CAFFIEND RISE

카피엔드의 슬로푸드 대기시간을 **문제 시간**이 아니라 **브랜드 경험 시간**으로 바꾸기 위한 모바일 웹 미니게임 MVP입니다.

## 1. Project Goal

카피엔드의 실제 현장 조건을 기준으로 설계했습니다.

- 수플레: 평소 약 20~30분, 피크타임에는 주문 적체로 최대 1시간까지 대기 가능
- 빙수: 약 10~15분
- 대기시간 컴플레인은 크지 않음
- 대기 중 고객들은 주로 각자 스마트폰을 사용
- 주요 고객은 20대 약 40%, 30~40대 약 40%, 그 외 50~60대이며 가족 단위 방문도 많음
- 사장님이 원하는 경험: **맛있는 메뉴 + 기분 좋은 기다림 + 더 좋은 경험**
- 4계절 제철과일과 수플레/디저트 제작 과정 자체를 브랜드 경험으로 확장하고 싶음
- 실시간 최고 기록을 갱신한 고객에게 할인/서비스/기록 보상 제공 가능

따라서 이 MVP의 목표는 `대기시간을 없애는 것`이 아닙니다.

> **Waiting Time → Brand Time**

고객이 이미 사용하는 스마트폰 안으로 카피엔드다운 짧은 놀이를 넣어, 대기시간의 체감과 브랜드 기억을 개선하는 것이 목표입니다.

## 2. Core Game

### CAFFIEND RISE

- 설명 한 줄: **수플레가 가장 폭신한 순간을 TAP**
- 플레이 시간: 25초
- 조작: 한 손 TAP
- 반복 루프: 부풀기 → 타이밍 TAP → 점수/콤보 → 즉시 다시 부풀기
- PERFECT 연속 성공 시 콤보 상승
- 5콤보마다 제철 과일 보너스
- 결과 화면에서 점수, 배지, 재도전, 공유 제공
- 브라우저 `localStorage`를 이용한 **기기 내 최고기록** 제공

게임을 복잡하게 만들지 않고, 수플레의 `폭신함 / 기다림 / 정성 / 제철`을 게임 언어로 사용합니다.

## 3. Why This Direction

단순 제작 시뮬레이션은 한 번 체험하면 끝나기 쉽습니다. 대기시간 체감 단축에는 `다시 한 번`을 만드는 짧은 반복 루프가 더 중요합니다.

따라서:

- **게임의 코어:** 단순 반복 타이밍 플레이
- **브랜드 세계관:** 수플레 제작 과정
- **시즌 운영:** 4계절 제철과일
- **마케팅 장치:** 기록 경쟁 / 결과 공유 / 매장 보상

으로 역할을 분리했습니다.

## 4. Run Locally

별도 설치가 필요 없습니다.

1. 저장소를 내려받습니다.
2. `index.html`을 브라우저에서 엽니다.

더 안정적으로 확인하려면 간단한 정적 서버를 사용합니다.

```bash
python -m http.server 8000
```

그 후 브라우저에서 `http://localhost:8000`으로 접속합니다.

## 5. GitHub Pages

이 프로젝트는 순수 HTML/CSS/JavaScript로 구성되어 있어 GitHub Pages에 바로 배포할 수 있습니다.

Repository → **Settings → Pages → Deploy from a branch → main / root**를 선택하면 됩니다.

> 이 저장소가 Private인 경우 계정/플랜 설정에 따라 Pages 사용 가능 범위가 다를 수 있습니다.

배포 후 생성된 URL을 QR 코드에 연결하면 매장 테스트가 가능합니다.

## 6. Current MVP Limitations

현재 v0.1은 게임 핵심 재미와 브랜드 톤을 검증하기 위한 버전입니다.

- 최고기록은 **기기별 localStorage** 기록입니다.
- 실제 매장 전체 고객이 공유하는 실시간 랭킹은 아직 없습니다.
- 실제 할인/서비스 보상 검증 로직은 아직 없습니다.
- 주문번호/POS/대기시간 시스템과 연결되어 있지 않습니다.
- 시즌 과일은 예시 설정이며, 실제 카피엔드 시즌 메뉴에 맞춰 수정해야 합니다.

실제 운영 시 `가짜 실시간 진행바`나 검증되지 않은 대기상태는 제공하지 않습니다.

- QR 진입 → 시작 → 완료까지 이탈 측정

### v0.3 — Shared Leaderboard
- Supabase/Firebase 등 간단한 백엔드 연결
- 당일/주간 최고기록
- 닉네임 없이 익명 코드 또는 주문번호 기반 기록
- 동일 고객의 무한 보상 방지 규칙

### v0.4 — Reward System
- `오늘의 기록 갱신` 조건
- 매장 운영 가능한 할인/토핑/서비스 보상
- 직원 확인용 간단한 인증 화면
- 보상 비용 상한 설정

### v0.5 — Seasonal Content
- 봄/여름/가을/겨울 테마
- 실제 시즌 수플레와 연동
- 시즌별 과일 보너스 및 결과카드
- Instagram Story 공유용 결과 이미지

### v1.0 — Waiting Experience
- 주문 시 예상 대기시간과 게임 진입 연결
- 실제 운영 데이터를 바탕으로 한 대기 UX
- 미니게임 → 메뉴 제작과정 → 먹는 방법 → 실제 메뉴 도착까지 하나의 브랜드 경험으로 연결

## 8. Validation Metrics

조회수보다 실제 대기경험과 행동을 봅니다.

- QR 진입률
- 게임 시작률
- 게임 완료율
- 평균 재도전 횟수
- 평균 플레이 시간
- 결과 공유율
- 참여자 vs 미참여자의 대기 체감시간 차이
- 참여 후 브랜드 기억도
- 기록 갱신 보상 사용률
